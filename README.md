Krankheiten
- Tiere können zufällig krank werden.
- Grundwahrscheinlichkeit pro Tier beträgt ungefähr 1,5 % pro Spieltag.
- Die Prüfung läuft stündlich.
- Folgende Krankheiten sind enthalten:
  - Atemwegsinfekt
  - Magen-Darm-Infekt
  - Fieber
  - Klauenentzündung
  - Parasitenbefall
- Erkrankungen werden einzelnen Tieren zugeordnet.
- Im Tiermenü wird angezeigt:
  - welches Tier krank ist
  - welche Krankheit vorliegt
  - wie lange noch Zeit zur Behandlung bleibt
- Bei einer neuen Erkrankung erscheint eine Benachrichtigung.
- Der Mod merkt sich, wie viele Stunden ein Tier bereits krank ist.
- Ein unbehandeltes Tier stirbt nach 72 Spielstunden.
- Beim Tod wird das konkrete Tier aus dem Stall entfernt.
- Es erscheint eine Meldung, dass das betreffende Tier an einer unbehandelten Krankheit gestorben ist.

Tierarzt / Behandlung
- Kranke Tiere können direkt über das Tiermenü behandelt werden.
- Grundgebühr des Tierarztes:
  - 350 €
- Behandlungskosten pro behandeltem Tier:
  - 125 €
- Eine einzelne Behandlung kostet damit:
  - 475 €
- Wenn der Betrieb nicht genug Geld hat, wird die Behandlung nicht durchgeführt.
- Nach erfolgreicher Behandlung:
  - Krankheit wird entfernt
  - Krankheits-Timer wird zurückgesetzt
  - Tier gilt wieder als gesund

Impfungen
- Tiere können einzeln geimpft werden.
- Kranke Tiere müssen erst Behandelt werden, dann können sie geimpft werden.
- Impfkosten:
  - 350 € Tierarzt-Grundgebühr
  - 50 € Impfung
  - insgesamt 400 € pro Tier
- Eine Impfung hält 12 Spielmonate.
- Während der Impfung sinkt das Erkrankungsrisiko um 90 %.
- Aus 1,5 % Erkrankungsrisiko pro Tag werden damit ungefähr 0,15 % pro Tag.
- Jeden Spielmonat wird die Restdauer um einen Monat reduziert.
- Im Menü steht beispielsweise:
  - „Bereit zur Impfung“
  - „Impfschutz: noch X Monate“
  - „Zuerst Krankheit behandeln“

Tiernamen
- Tiere erhalten individuelle Namen.
- Tiere können im Tiermenü manuell umbenannt werden.
- Eigene Tiernamen dürfen bis zu 96 Zeichen lang sein.
- Namen werden im Spielstand gespeichert.

Künstliche Befruchtung
- Der Mod führt ein eigenes System für künstliche Befruchtung ein.
- Bei unterstützten Tieren wird die normale automatische Fortpflanzung deaktiviert.
- Es gibt eine eigene Aktion:
  - „Künstliche Befruchtung“
- Standard-Tastenkürzel:
  - I
- Man wählt ein bestimmtes Tier aus.
- Das Tier muss:
  - fortpflanzungsfähig sein
  - das erforderliche Mindestalter erreicht haben
  - aktuell nicht bereits befruchtet sein
  - keinen laufenden Fortpflanzungs-Cooldown haben
Kosten der künstlichen Befruchtung
- Tierarzt-Grundgebühr:
  - 350 €
- Befruchtung:
  - 250 €
- Insgesamt:
  - 600 € pro Tier
- Ohne genügend Geld findet keine Befruchtung statt.
Mindestalter und Tragezeiten
Der Mod besitzt Standardwerte, falls die Tierdefinition selbst keine Werte vorgibt:
- Kühe
  - geschlechtsreif ab ca. 18 Monaten
  - Tragezeit: 10 Monate
- Schweine
  - ab ca. 6 Monaten
  - Tragezeit: 4 Monate
- Schafe
  - ab ca. 8 Monaten
  - Tragezeit: 5 Monate
- Ziegen
  - ab ca. 16 Monaten
  - Tragezeit: 5 Monate
- Pferde
  - ab ca. 22 Monaten
  - Tragezeit: 11 Monate
- Wenn eine Tier-/Mapdefinition eigene Werte besitzt, versucht der Mod diese stattdessen zu benutzen.
Trächtigkeitsanzeige
- Für jedes befruchtete Tier wird der Fortschritt separat gespeichert.
- Im Menü wird angezeigt:
  - „Bereit für künstliche Befruchtung“
  - „Befruchtet – restliche Tragezeit: X Monate“
  - „Geburt in X Monaten“
  - „Geburt jetzt“
  - „Geburt wartet auf freien Stallplatz“
  - „Nicht fortpflanzungsfähig“

Anzahl der Jungtiere
Der Mod simuliert Würfe abhängig von der Tierart.
- Kühe
  - normalerweise 1 Kalb
- Schweine
  - 10–14 Ferkel
- Schafe
  - 1–2 Lämmer
- Ziegen
  - 1–3 Jungtiere
- Bei anderen unterstützten Arten verwendet der Mod standardmäßig meist 1 Jungtier.
Totgeburten
Der Mod simuliert zusätzlich Totgeburten.
- Kühe:
  - ungefähr 10–20 %
- Schweine:
  - ungefähr 5–10 %
- Schafe:
  - ungefähr 2–5 %
- Ziegen:
  - ungefähr 2–5 %
- Bei der Befruchtung wird eine individuelle Rate innerhalb dieses Bereichs festgelegt.
- Bei der Geburt wird für jedes erwartete Jungtier entschieden, ob es lebend geboren wird.
- Nach einer Geburt erscheint eine Meldung wie:
  - Anzahl lebender Jungtiere
  - Anzahl der Totgeburten
Fortpflanzungs-Pause
Nach einer Befruchtung/Geburt gibt es zusätzlich einen Cooldown.
- Kühe:
  - ungefähr 12 Monate
- Schweine:
  - ungefähr 6 Monate
- Schafe:
  - ungefähr 12 Monate
- Ziegen:
  - ungefähr 12 Monate
- Im Menü kann angezeigt werden:
  - „Nächste Befruchtung in X Monaten“

Voller Stall bei einer Geburt
- Der Mod prüft bei einer Geburt den freien Platz.
- Ist genug Platz vorhanden:
  - Jungtiere werden dem Stall hinzugefügt.
- Ist der Stall teilweise voll:
  - so viele Jungtiere wie möglich bleiben im Stall.
- Überschüssige Jungtiere werden automatisch verkauft.
- Der Verkaufspreis basiert auf dem normalen Verkaufspreis eines neugeborenen Tieres.
- Es erscheint eine Meldung über:
  - Anzahl automatisch verkaufter Jungtiere
  - Verkaufserlös

Milchproduktion
Ein wichtiger Teil des Mods betrifft die Milchproduktion.
- Bei normalen milchgebenden, fortpflanzungsfähigen Tieren soll Milchproduktion an eine Geburt gekoppelt sein.
- Nach einer Geburt startet eine Laktationsperiode.
- Diese dauert:
  - 12 Monate
- Nach Ablauf der 12 Monate endet die durch den Mod gesteuerte Milchproduktion wieder.
- Das Tier muss anschließend erneut Nachwuchs bekommen, damit eine neue Laktation startet.
- Bereits vorhandene oder neu gekaufte Tiere ohne gespeicherten Laktationsstatus produzieren entsprechend der Modbeschreibung zunächst keine normale geburtsabhängige Milch.
- Sie müssen erst Nachwuchs bekommen.
- Der Mod berechnet dabei die normale altersabhängige Milchkurve des Tieres weiter.

Tiere mit weiterhin normaler Fortpflanzung
Bestimmte Tiere werden ausdrücklich nicht auf künstliche Befruchtung umgestellt.
Dazu gehören insbesondere:
- Hühner
- Hähne
- Enten
- Wildenten
- Gänse
- Wachteln
- Hirsche
- bestimmte geschorene Schafvarianten
Bei diesen Tieren bleibt die durch das Spiel bzw. die Map gesteuerte Fortpflanzung bestehen.
Bereits bestehende Trächtigkeiten
- Wenn beim Aktivieren des Mods bereits eine normale Trächtigkeit läuft, wird diese nicht einfach gelöscht.
- Eine bereits laufende natürliche Schwangerschaft darf zu Ende laufen.
- Danach greift bei unterstützten Tieren das System der künstlichen Befruchtung.

Wichtige Auswirkungen auf normales FS25-Gameplay
- Unterstützte Säugetiere vermehren sich nicht mehr einfach automatisch, sobald die normale Reproduktionsanzeige leer ist.
- Man muss die Tiere stattdessen aktiv künstlich befruchten.
- Milchvieh wird stärker an reale Geburts-/Laktationszyklen gekoppelt.
- Krankheiten können echte Tierverluste verursachen.
- Impfungen werden dadurch wirtschaftlich sinnvoll.
- Fortpflanzung kostet Geld.
- Tierhaltung erfordert dadurch deutlich mehr Management.
- Einzelne Tiere bekommen wesentlich mehr Bedeutung.
